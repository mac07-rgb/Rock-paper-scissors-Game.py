# Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python.

## Features

- Play Rock Paper Scissors against the computer
- Computer chooses a move randomly
- Detects wins, losses, and ties
- Allows multiple rounds
- Handles invalid input
- Uses Python `Enum` for game moves

## How It Works

The player chooses one of three moves:

- `0` - Rock
- `1` - Paper
- `2` - Scissors

The computer randomly selects one of the three moves.

The winner is determined using the standard rules:

- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper
- Same move = Tie

## Requirements

- Python 3.8 or newer

No external Python packages are required.
